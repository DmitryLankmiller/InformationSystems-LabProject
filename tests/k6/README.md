# k6

Команды выполняются из `tests/k6`. Нужны установленный k6 и запущенный бэкенд.

```sh
cd tests/k6
npm ci
npm run test:crud
npm run test:update
npm run test:delete
npm run test:duplicates
npm run test:import
npm run test:import-rollback
```

По умолчанию: `https://se.ifmo.ru/~s373305/is/api`, 5 клиентов, в CRUD — 3 итерации на клиента.
Адрес и нагрузку можно поменять при запуске:

```sh
VUS=10 npm run test:delete
VUS=10 ITERATIONS=5 npm run test:crud
```

В каждом TS-файле: `options`, необходимые `setup`, сам сценарий и `teardown`.
Общей конфигурации и HTTP-обёрток нет.

| Команда                | Что проверяет                                                                                                                   |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `test:crud`            | Создание, чтение, PATCH, удаление. Поля и связи сохранены, удалённый город недоступен, его координаты можно использовать снова. |
| `test:update`          | Одновременные PATCH одного города: `N × 200`. Итоговые площадь и население принадлежат одному PATCH.                            |
| `test:delete`          | Удаление одного города: `1 × 204`, `N−1 × 409`. Затем GET возвращает `404`.                                                     |
| `test:duplicates`      | Одна пара координат у разных городов: `1 × 201`, `N−1 × 409`. Сохранён ровно один город.                                        |
| `test:import`          | Каждый клиент загружает 3 города: `N × 202`, затем `N × SUCCESS`. Проверяются владелец, счётчик, поля и вложенные объекты.      |
| `test:import-rollback` | CSV с повтором координат: `N × 202`, затем `N × FAILED`. Города не сохраняются, координаты доступны для повторной вставки.      |

Счётчики ответов относятся только к запросам сценария, без подготовки и очистки.
Точные количества заданы в `thresholds`; любой проваленный `check` тоже завершает тест
с ненулевым кодом. Ожидаемые `409` не считаются HTTP-сбоем.
Для PATCH без версий допустимы несколько успешных обновлений. `202` импорта означает
приём файла; тест опрашивает историю до завершения обработки.

Тесты удаляют свои города. Учётные записи импортов, история и губернаторы остаются:
для них нет DELETE API. Уникальность названий не проверяется.

Гонки ориентируются на общее время старта. Для проверки конкурентного доступа нужно
как минимум 2 клиента; повторяй запуск, чтобы повысить вероятность пересечения транзакций.
`500` вместо `409` или несколько успешных удалений должны провалить тест.

Проверки без нагрузки:

```sh
npm run test:typecheck
k6 inspect concurrent-delete.ts
```

Дополнительные аргументы k6 передаются после `--`, например:

```sh
npm run test:delete -- --summary-export /tmp/k6-delete.json
```

k6 запускает [TypeScript напрямую начиная с v0.57](https://grafana.com/docs/k6/latest/using-k6/javascript-typescript-compatibility-mode/).
`npm ci` устанавливает только TypeScript и типы для проверки кода; сам k6 устанавливается отдельно.
